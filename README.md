# ✅ Gerenciador de Tarefas

Um gerenciador de tarefas simples e funcional desenvolvido com **HTML, CSS e JavaScript**, criado com o objetivo de praticar conceitos fundamentais de desenvolvimento Front-End e manipulação do DOM.

O projeto permite organizar tarefas diretamente pelo navegador e utiliza o **Local Storage** para manter os dados salvos mesmo após fechar ou atualizar a página.

## 🚀 Funcionalidades

* ➕ Adicionar novas tarefas
* ✅ Marcar tarefas como concluídas
* 🗑️ Excluir tarefas
* 💾 Salvamento automático no Local Storage
* 🔄 As tarefas permanecem salvas após atualizar a página
* 🚫 Impede a criação de tarefas vazias

## 🛠️ Tecnologias utilizadas

* **HTML5** — estrutura da aplicação
* **CSS3** — estilização da interface
* **JavaScript** — lógica e manipulação das tarefas
* **Local Storage** — armazenamento das tarefas no navegador
* **Git & GitHub** — versionamento do projeto

## 💻 Como executar

Clone o repositório:

```bash
git clone https://github.com/Thiag0Wm/GERENCIADOR-DE-TAREFAS.git
```

Entre na pasta do projeto:

```bash
cd GERENCIADOR-DE-TAREFAS
```

Depois, abra o arquivo:

```text
index.html
```

Você também pode utilizar a extensão **Live Server** no Visual Studio Code.
